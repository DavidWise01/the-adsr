# THE ADSR ENVELOPE · one pitch, many instruments

A member of **[MUSIC · this one time at band camp](https://davidwise01.github.io/ud0/d/music.html)** — part of **UD0**, the biosphere of David Lee Wise / ROOT0.

Attack, Decay, Sustain, Release: four numbers turn one oscillator into a pluck or a pad — timbre in time, not pitch. Morph pluck→pad and play the shape.

**House layout:** the full four corners — a **technical** layer (real mechanism + LIT/AMBER + fail-loud self-check), a **2D** measure canvas, a **real-WebGL 3D** canvas, and a **toddler's corner** — bound by one shared parameter, **plus a ▶ play button** (offline Web Audio, nothing sent anywhere).

Open [`index.html`](index.html). Offline, self-contained, 0 external requests. CC-BY-ND-4.0, with AVAN.
